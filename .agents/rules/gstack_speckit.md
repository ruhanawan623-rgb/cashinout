# Engineering Governance: GStack + SpecKit + Test Skill + Google Standards

## 1. SpecKit Workflow
Always follow Spec-Driven Development:
1. **Constitution:** Define immutable principles, design constraints, and tech boundaries.
2. **Specification:** Detail functional specs, user stories, and acceptance criteria.
3. **Plan:** Establish architecture, data models, state flows, and modular design.
4. **Tasks:** Break down work into verifiable, discrete tasks.
5. **Implement:** Execute strictly in accordance with approved specs.

## 2. GStack Multi-Role Reviews
Evaluate implementations through specialized engineering lenses:
- **Product & CEO:** Value proposition, delightful user flow, clarity of navigation.
- **Lead Designer:** Rich aesthetics, curated color palettes, glassmorphism, micro-animations, modern typography.
- **Architect:** Clean separation of concerns (storage, business logic, rendering).
- **QA / Test Engineer (Test Skill):** TDD, test matrices, boundary condition handling, validation of interactive states.
- **Security Auditor:** Input sanitization, safe storage, error boundaries.

## 3. Google Antigravity Web Quality
- Avoid generic colors and browser defaults.
- Zero placeholder images.
- Fast, fluid, responsive, and engaging UI.
